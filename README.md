## Featured Projects

### 1. Cybersecurity Virtual Home Lab

A virtual enterprise environment designed to simulate the infrastructure commonly found within an organization. This project focuses on system administration, network configuration, security monitoring, and the management of Windows and Linux environments. 

**Key Skills Demonstrated:**

- Windows Server 2022 and Active Directory administration
- DNS, DHCP, and Group Policy configuration
- User and group management
- Linux server administration
- Network traffic analysis
- Virtualization and network troubleshooting

**Technologies used:** Windows Server, Windows 11, Ubuntu Server, Kali Linux, VirtualBox, Wireshark, and Nmap.

### 2. AWS Cloud-based Honeypot

A cloud-based cybersecurity project focused on deploying a honeypot environment to observe and analyze potentially malicious activity. The project explores how honeypots can be utilized to collect security-related data and better understand external threats and attacker behavior. 

**Key skills demonstrated:**
- Cloud infrastrucutre deployment
- AWS EC2 instance configuration
- Linux system administration
- Network security and firewall configuration
- Threat detection and security event monitoring
- Honeypot deployment and management
- Containerized environments

**Technologies used:** AWS EC2, T-Pot, Ubuntu, Docker, Cowrie, Suricata, and SpiderFoot.

### 3. Machine Learning Analysis

A project exploring the implementation of machine learning techniques to analyze data and develop predictive models. Although this project is not directly related to cybersecurity, it demonstrates my programming, analytical, and problem-solving abilities, as well as my interest in AI and emerging technologies. 

**Key skills demonstrated:**

- Python programming
- Data preprocessing and analysis
- Machine learning model implementation

**Technologies used:** Python, Google Colab, and machine learning libraries
